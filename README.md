# 영양제 재고 관리 시스템 
## 프로젝트 소개
---
여러 영양제를 복용하는 사용자가 재고를 일일이 확인하지 않고도, 함께 주문하면 효율적인 영양제 목록과 주문 시점을 확인할 수 있도록 돕는 서비스

**문제**: 영양제를 여러가지 복용하면 각 제품의 남은 수량과 배송 소요 기간을 고려해 주문 시점을 직접 계산해야 한다
**해결**: 복용량, 복용 주기, 현재 재고, 배송 리드타임, 안전 재고일을 기반으로 소진 예정일과 주문 권장일을 자동 계산한다.

## 프로젝트 기술 소개
---
프로젝트에 사용된 언어, 기술, ERD 와 개발환경 등을 소개합니다
